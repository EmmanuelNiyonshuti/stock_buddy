# stock_buddy - Small Business Stock Tracker

## Overview
**stock_buddy** is a comprehensive inventory management system designed for small businesses to streamline their stock tracking and transactions. The system includes both a backend API built with **Flask** and a **frontend** for user interaction. currently its a backend RESTful API. This project aims to replace manual stock management methods, such as pen/paper and spreadsheets, with an efficient, user-friendly, and scalable solution.
