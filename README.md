# stock_buddy  - Inventory management system.

## Overview

stock_buddy is an inventory management system designed to help small businesses track inventory levels, manage stock movements, and receive low-stock alerts. It provides seamless product and transaction management while ensuring secure data handling.

Currently, Stock_buddy is a RESTful API backend.

## Features
* Product Management – CRUD on products.
* Inventory Tracking – Monitors stock levels based on transactions.
* Low-Stock Alerts – Notifies when stock falls below a threshold.
* Transaction Logging – Records purchases and sales.
* Authentication – Secure access using JWT.

## Tech Stack
* Backend: Flask, SQLAlchemy, MySQL
* Authentication: JWT
* Data Storage: MySQL
