# stock_buddy - Small Business Stock Tracker

## Overview
**Stock Buddy** is a RESTful API backend designed to help small businesses efficiently manage their inventory. It aims to replace traditional stock tracking methods—such as pen-and-paper or spreadsheets—with a more streamlined, scalable, and user-friendly solution.

This project is built using the **Flask** microframework for its simplicity and flexibility in developing lightweight web applications. It utilizes **MySQL** as the database for its reliability and structured data management. Authentication is handled using **cookie-based JWT authentication**, ensuring secure user sessions.

The API is fully documented using **Swagger** through **Flasgger**, allowing developers to explore and test endpoints directly from an interactive interface.

Currently, the API provides essential endpoints for managing stock, products, and transactions. A frontend interface may be developed in the future to enhance user interaction.
